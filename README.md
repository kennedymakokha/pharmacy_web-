# Pharmacy Management System (React)

## Requirements
- Node.js 18 or later
- npm

## Run locally
1. Extract the ZIP file.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Included pages
Dashboard, Medicines, Categories, Sales, Purchases, Inventory, Customers, Suppliers,
Prescriptions, Reports, Staff & Users, and Settings.

## Important
This is a front-end prototype. It uses sample data held in React state. It does not yet
connect to MySQL or implement real authentication, server-side permissions, persistent
storage, prescription compliance checks, or production backup/restore. Connect the forms
and actions to your backend/API before using real pharmacy data.
